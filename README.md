# BiGROUP Landing Page

Astro + Tailwind recreation of the [Hyperbit Astro](https://themefisher.com/products/hyperbit-astro) home layout, customized for **BiGROUP**.

## Stack

- Astro 7
- Tailwind CSS v4
- Swiper (flagship + trusted-by carousels)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
