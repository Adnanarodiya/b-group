# Bi Group — Landing Page

A modern, responsive landing page for **Bi Group**, built with [Astro](https://astro.build) and Tailwind CSS.

## Sections

- **Hero** — Full-screen hero with brand messaging
- **About Bi Group** — Company overview with key metrics
- **Business Verticals** — All 10 business units (Paints, Kitchen, Agriculture, etc.)
- **At a Glance** — Stats strip
- **Flagship Spotlight** — Bi Paints feature section
- **Trusted By** — Client logos marquee (L&T, Godrej, MoD, etc.)
- **Why Bi Group** — Six key differentiators
- **Contact CTA** — Contact form and details
- **Footer** — Full navigation and social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- [Astro 7](https://astro.build)
- [Tailwind CSS 4](https://tailwindcss.com)
- [Inter](https://fonts.google.com/specimen/Inter) font family
